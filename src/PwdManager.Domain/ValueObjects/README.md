# Domain / ValueObjects

Bu klasör, kimliği olmayan (yalnızca değeriyle eşitlenen) küçük, değişmez
domain tiplerine ayrılmıştır — ör. `CipherBlob`, `RecoveryCode`, `KdfSalt` gibi
sarmalayıcılar.

Şu an uygulamanın domaini bilinçli olarak ince tutulduğundan burada tanımlı bir
value object yoktur; ihtiyaç oldukça buraya eklenir. Yer tutucudur.
